# ShiftPay privacy policy

Public privacy-policy page for **ShiftPay: Shifts, Jobs & Pay**, published by **Option F**.

## GitHub Pages publication

Recommended repository name: `shiftpay-privacy`

1. Create a public GitHub repository named `shiftpay-privacy`.
2. Put the files from this directory in the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select branch `main` and directory `/ (root)`, then save.
5. The expected URL is `https://GITHUB-USERNAME.github.io/shiftpay-privacy/`.
6. Open the URL in a signed-out browser and confirm that it loads without a login.
7. Enter that exact HTTPS URL in Google Play Console's **Privacy policy URL** field.

The app must also expose this same policy URL from an always-available in-app entry, for example **Settings → Privacy policy**. Google's advertising-consent settings alone do not replace the policy link.
